常見問題

開始使用 DOBO 前，先解答你的疑問。

可以免費開始使用嗎？

無需綁定信用卡即可建立帳戶，並以基本點數體驗所需功能。

需要哪個 AI 帳戶？

Terminal、Auto Space 和 Present AI 需要連接 CLI 或 API 帳戶。

Research 無需另外的 API 金鑰即可使用。

如何使用 Research？

新增感興趣的主題，即可彙整調查結果。閱讀重點內容，並透過原文了解更多資訊。

在哪裡管理帳戶與付款？

在「我的帳戶」中可以查看點數餘額與付款紀錄、儲值點數並管理訂閱。

什麼時候會新增功能？

我們計劃每月推出一個新功能。
