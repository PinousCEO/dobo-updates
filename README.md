# DOBO desktop updates

This repository hosts official DOBO desktop installers and automatic update metadata.

## Downloads

Verified public releases will appear on the [Releases page](https://github.com/PinousCEO/dobo-updates/releases). No installer has been published yet.

## Automatic updates

Installed Windows apps check published stable releases, download updates in the background, and offer a restart after active work has finished. Draft and prerelease builds are not offered to stable clients.

Release assets include the Windows installer, its blockmap, and latest.yml. Account data, credentials, build logs, and the development repository are not uploaded here.
