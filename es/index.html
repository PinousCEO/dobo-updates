Preguntas frecuentes

Resuelve tus dudas antes de empezar con DOBO.

¿Puedo empezar gratis?

Crea una cuenta sin añadir una tarjeta y prueba las herramientas que necesitas con tus créditos básicos.

¿Qué cuenta de IA necesitas?

Terminal, Auto Space y Present AI requieren una cuenta CLI o API conectada.

Research funciona sin una clave API adicional.

¿Cómo se usa Research?

Añade temas que te interesen para reunir resultados de investigación. Lee los puntos clave y consulta las fuentes originales para obtener más detalles.

¿Dónde gestiono mi cuenta y mis pagos?

En Mi cuenta puedes consultar tu saldo de créditos y el historial de pagos, recargar créditos y gestionar tu suscripción.

¿Cuándo se añadirán nuevas funciones?

Tenemos previsto incorporar una nueva función cada mes.

¿También se puede usar LINGO?

LINGO is in development. It will be available when it is ready.
