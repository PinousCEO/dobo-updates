常见问题

开始使用 DOBO 前，先解答你的疑问。

可以免费开始使用吗？

无需绑定银行卡即可创建账户，并用基础积分体验所需功能。

需要哪种 AI 账户？

Terminal、Auto Space 和 Present AI 需要连接 CLI 或 API 账户。

Research 无需单独的 API 密钥即可使用。

如何使用 Research？

添加感兴趣的主题，即可汇总调查结果。阅读重点内容，并通过原文了解更多信息。

在哪里管理账户和付款？

在“我的账户”中可以查看积分余额和付款记录、充值积分并管理订阅。

什么时候会添加新功能？

我们计划每月推出一个新功能。

也可以使用 LINGO 吗？

LINGO is in development. It will be available when it is ready.
