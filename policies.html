기존 Research 기간제 Task를 실행당 요금으로 전환하면 남은 기간 비율에 해당하는 선결제 크레딧을 소수점 아래 버림하여 한 번 복원합니다. 과거 실행은 소급 청구하지 않습니다. 실행당 크레딧은 기능 이용료이며 실측 API 원가 청구가 아닙니다. 같은 주기에는 1회 재시도가 가능하며, 기간 전체 시도 횟수는 예정 실행 수에 20%(올림)를 더한 횟수 이내입니다. 추가 태스크의 크레딧 자동 갱신은 선택한 경우에만 적용하며, 태스크를 정지하거나 삭제하면 갱신하지 않습니다. 놓친 주기의 조사는 소급 실행하지 않습니다. 결제 취소 시 해당 결제의 크레딧을 회수하며 이미 사용한 크레딧이 있으면 계정 확인이 필요할 수 있습니다. 환불 요청은 주문번호와 함께 고객지원에 제출합니다. 정식 환불 기준·청약철회 고지·운영자 정보 확정 전에는 실제 유료 충전을 제공하지 않습니다.

서버·백업 업체, 실제 사용할 로그인·이메일·결제 서비스의 위탁 및 국외 이전 내역을 반영한 뒤 시행일을 공지합니다. 아래 보관·파기 기준은 출시 시 적용할 기준이며, 해당 운영 절차를 갖춘 뒤 서비스를 공개합니다.

1. 처리 목적·항목 및 수집 방법

회사는 회원 가입과 계약 이행에 필요한 범위에서 개인정보를 처리합니다. 선택적 처리에 동의가 필요한 경우 별도 동의를 받으며, 법령에 따른 보관은 해당 법령을 근거로 합니다.

  • 회원 가입·로그인: 선택한 로그인 제공자의 사용자 식별자, 이름 또는 닉네임, 제공자가 확인한 이메일 주소(제공되는 경우), DOBO 계정 식별자와 가입 시각을 처리합니다. 이메일 로그인에는 입력한 이메일 주소를 사용합니다. 외부 로그인 비밀번호는 수집하지 않습니다.
  • 인증·서비스 보호: 로그인 세션, 인증 요청·만료 시각, 인증용 난수, 요청 횟수와 제한 시각을 처리합니다. 서버 통신 과정에서 접속 IP를 처리하며, API 요청 제한용 데이터베이스에는 IP의 해시값을 사용합니다.
  • 이용권·크레딧·작업 정산: 계정 식별자, 지급·차감·환급 내역, 작업 식별자·제목·종류·상태·시각, Research 태스크 제목·주기·기간·갱신 설정과 실행 이력을 처리합니다. 작업 제목에는 입력 내용 일부가 포함될 수 있습니다.
  • 결제 기능 이용 시: 주문 식별자, 상품·통화·금액, 결제·환불·구독 상태, 결제사 거래 식별자와 이용 기간을 처리합니다. 카드번호·보안코드는 결제사 화면에서 처리하며 DOBO 계정 서버에는 저장하지 않습니다.
  • 문의·권리 행사: 이용자가 제공한 이메일·연락처, 문의 내용, 필요한 주문·계정 식별 정보 및 처리 결과를 처리합니다. 문의에 비밀번호·카드번호·API 비밀키를 포함하지 마세요.

정보는 회원의 직접 입력, 선택한 로그인 제공자의 인증 응답, 앱과 서버의 통신 및 결제사 응답을 통해 수집됩니다. 필수 정보 제공을 거부하면 해당 로그인·결제·계정 기능 이용이 제한될 수 있습니다.

작업 파일·대화·설정·결과물은 사용자의 기기에 저장됩니다. AI 기능 실행 시 선택한 CLI 또는 API 제공자에게 프롬프트, 실행에 필요한 파일·이미지·맥락이 전송될 수 있으며, 해당 제공자의 처리방침과 이용자가 선택한 설정이 적용됩니다. 회사가 제공자 측 보관 기간이나 학습 이용 여부를 일괄 보장하지는 않습니다.
