어떤 AI 계정이 필요한가요?

Terminal·Auto Space·Present AI에는 연결한 CLI 또는 API 계정이 필요합니다.

Research는 별도의 API 키 없이 이용할 수 있습니다.

Research는 어떻게 이용하나요?

관심 주제를 등록하면 조사 결과를 모아볼 수 있습니다. 핵심 내용을 읽고, 더 자세한 정보는 원문에서 확인하세요.

계정과 결제는 어디서 관리하나요?

내 계정에서 크레딧 잔액과 결제 내역을 확인하고, 충전과 구독을 관리할 수 있습니다.
